nb-hub 是一个面向 AI / LLM 外围生态的资源聚合站，聚焦 **开发框架、工具提效、MCP 生态、部署运维、应用与导航** 五个方向。它不是把所有链接粗暴堆在一个页面里，而是先用首页做分类入口、快速入口与精选卡片，再把完整浏览、搜索与筛选放到独立资源库页。

整个项目采用 **HTML + CSS + Vanilla JavaScript** 实现，无构建步骤、无 Node 依赖、无后端服务，适合直接作为静态站点托管到 GitHub Pages 或其他静态平台。

## 项目亮点

- 🎯 **首页 / 资源库分层**：首页负责导航入口、路线卡片和趋势观察，完整浏览放在 `explore.html`。
- 🔍 **资源可搜索可筛选**：支持关键词搜索、分类切换、仅看精选，并同步到 URL 查询参数。
- ✨ **精选 + 管理员短评**：精选状态与短评可从管理页维护，并同步到前台卡片展示。
- 🧩 **数据集中维护**：资源主数据统一放在 `docs/data.js` 中，新增项目只需补一条数据。
- 📝 **轻量 CMS 管理页**：`docs/admin.html` 支持单项编辑、批量精选、复制覆盖 JSON、发布到 GitHub。
- 🌐 **纯静态可部署**：`docs/` 可直接部署到 GitHub Pages，所有资源路径均为相对路径。
- 💾 **本地草稿预览**：本地打开页面时，可通过浏览器 `localStorage` 暂存未发布修改。

## 适合谁使用

- 想快速扫一遍 AI 开源生态，而不是在社媒和仓库之间反复跳转的人
- 正在做 Agent、MCP、LLM 工具链、网关或 AI 应用选型的人
- 想维护一个轻量、可持续更新、无需后端的资源导航站的人
